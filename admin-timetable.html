Exam timetable

Paste the official timetable, check the preview, then publish it. Nothing goes live until you tick the box and save the file on GitHub.

1. Paste the timetable

In Excel or Google Sheets, use these column titles in the first row: date, code, title, start, end, venue, programme, year, semester. Select all the cells, copy, and paste here. Or choose a CSV file.

Use All for programme, year or semester when an exam is for everyone. Dates can be 2027-01-12 or 12/01/2027. Times like 09:00 or 2:00pm.

You can choose several files at once (for example one per programme). They are joined together.

2. Compare with the live one (optional)

To highlight what changed, paste the current timetable.json from GitHub here. Leave empty the first time.

3. Publish

Do these in order on GitHub:

1. Open timetable.json, paste everything over what is there, and tap Commit changes. The site updates in about a minute and students see an UPDATED label.
