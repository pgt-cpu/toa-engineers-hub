Novapoint Water and Sewer

Novapoint Water and Sewer is an AutoCAD based program for constructing pipelines and manholes for all types of water and sewer projects. The program is easy to use and includes all necessary functions for configuration, construction, cross section viewer, calculations, drawings and reports. With the configuration function the user is able to configure all the details of a Water and Sewer project. This can be types of pipes, manholes and other connections, materials, dimensions of pipes and manholes, rules for plan and profile drawings with line type, color and line thickness. In addition the user configures cross sections of the trench with types of pipes and where the pipes is placed in the trench. All constructions are done simultaneously in plan and profile.

  • Professional tool for all types of Water and Sewer projects

Terrain model
Novapoint Water and Sewer includes the Novapoint Terrain model. The terrain model has import functions from several standard map formats including import of 3D map data from an AutoCAD drawing. A separate function makes it easy to create a terrain model based on a surveyed terrain section. 

Configuration
In configuration the users sets up all rules and parameters for the project. This is parameters for types of pipes and manholes, dimensions, materials and standard dimensions for each type of material. You can also define color, layer and line type for each type of pipe and manhole / connection. These parameters will be used for drawing production. All parameters like distance to trench wall, cut slopes, specifications for trench bottom are also specified in configuration. In addition you also specify parameters for types of fill materials for the volume calculation.

The user can define different cross sections with number of pipes, type of pipe and material and dimension. In additions you specify where each pipe is placed in the trench and the distance between the pipes. Both theoretical and real distances between the pipes are calculated. 

Construction
The construction function has a dialog where all available sections are displayed together with all editing functions for construction. Construction is done in plan and profile simultaneously. The user can edit parameters for each object of the project in the dialog or use the object properties menu for the selected object. Based on the configuration pipes, manholes and other connections are automatically connected to the trench. Editing is very easy both geometrically and by parameters in the construction dialogue.

All changes are automatically updated in both plan and profile. The user can at any time move, delete and add trenches, sections, pipes and connections as well as change the elevation of pipes and connections. 

Cross section viewer
This is a function for viewing the calculated cross sections of the trench with the pipes and terrain. The view shows the pipes and all the layers in the trench. Selected cross sections can easily be drawn as a basis for detailed drawings. 

Reports
Novapoint Water and Sewer includes a set of standard reports. These reports are set out data and quantities for pipes and manholes, and volumes for the trench. It’s easy to import your company’s logo for all the reports. 

Drawings
Novapoint Water and Sewer include functions for generating typical drawings like plan drawing, longitudinal profile, cross sections and manhole sketches. All these drawings are automatically generated from the Water and Sewer project.
