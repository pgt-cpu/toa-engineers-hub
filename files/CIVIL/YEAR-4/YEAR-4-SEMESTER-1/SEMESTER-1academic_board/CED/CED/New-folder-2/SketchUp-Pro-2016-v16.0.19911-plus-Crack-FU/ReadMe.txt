INSTALL NOTES:

1. Install SketchUp Pro 2016.

2.Copy "SketchUp.exe" to [C:\Program Files\SketchUp\SketchUp 2016]
 OR [C:\Program Files (x86)\SketchUp\SketchUp 2016]

3. Copy "LayOut.exe" to [C:\Program Files\SketchUp\SketchUp 2016\LayOut
] OR [C:\Program Files (x86)\SketchUp\SketchUp 2016\LayOut
]

4. Copy "Style Builder.exe" to [C:\Program Files\SketchUp\SketchUp 2016\Style Builder] OR [C:\Program Files (x86)\SketchUp\SketchUp 2016\Style Builder]

5. Run the Application & Enjoy...!!!
