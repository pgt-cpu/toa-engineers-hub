PUT YOUR PDFs HERE, ARRANGED IN FOLDERS. The site reads the folders by itself.

Example:
  files/Civil/Year 2/Semester 1/CVE 251 Structures/Past Questions/CVE251 2023.pdf
  files/Civil/Year 2/Semester 1/CVE 251 Structures/Lecture Notes/Chapter 1.pdf
  files/Common/Year 1/Semester 1/EMA 151 Engineering Mathematics/Past Questions/EMA151 2022-2023.pdf
  files/Mechanical/Year 4/Timetable.pdf

Only Programme and Year folders are needed. Semester, Course and Type folders are optional.
Use the folder name "Common" for first-year courses shared by every programme.
Add (important) or (verified) to a file name to mark it. Example: 2023 solutions (verified).pdf
