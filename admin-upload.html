Upload a folder

Pick your folder of PDFs. This page tidies the file names, works out the programme, year, semester and course from your folders, and uploads everything to GitHub in safe batches. If it stops, run it again: files already uploaded are skipped.

1. Connect to GitHub

How do I get the key? (once)

1. On GitHub: your picture > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
2. Name it "Hub upload". Expiry: 30 days. Repository access: Only select repositories and choose your Hub project.
3. Permissions > Repository permissions > Contents: Read and write. Generate, copy it and paste it above.
The key lives only in this page while it is open. It is never saved in your site. Delete it on GitHub when you finish.

2. Choose the folder

Works on a computer (Chrome, Edge, Safari, Firefox). Phones cannot pick folders: use the next box to choose several files instead.
